# Fano_resonance_in_polymer_metasurface
Analysis of sharp Fano type resonance in polymer metasurface with (relatively) low refractive index contrast.
The resonance at 1.55 um wavelength was obtained by parametric sweep.
Accurate calculation of enhancement factor requires the knowledge of exact resonance wavelength.
It will be required to get the transmission data in a first simulation run, and find the resonance wavelength before continuing towards near-field plots and multipole decompsoition.
Once the resonance wavelength is known, use that value in the cell where the monitors for near-field measurement and mulitpole decomposition is defined.
After that clear simulation cache (cell number 3) and re-run the simulation. After that the near-field plot and multipole decomposition can be done.
